# starkeys

瀏覽器鋼琴練習工具。開啟 [index.html](index.html) 使用；部署時請一併保留 [local-sheet-recognition.js](local-sheet-recognition.js)、[piano-curriculum.js](piano-curriculum.js) 及 [microphone-auto.js](microphone-auto.js)。收音需要瀏覽器授權及 HTTPS（本機開發可用 localhost）。

## 24 關兒童教程

面向 5–8 歲初學者，每次約 5–10 分鐘；未熟可以重玩或用 0.6x 慢練。

| 關卡 | 重點 |
| --- | --- |
| 1–4 | 中央 C、右手五指、小羊、跳音程 |
| 5–8 | 左手三音及低音、長短拍、鈴兒響叮噹 |
| 9–12 | 歡樂頌、G 手位、小星星移位、左右手接力 |
| 13–16 | 右手穿指及 C 音階、左手跨指及音階 |
| 17–20 | 成對半拍、小蜜蜂接力、黑鍵、簡化小步舞曲 |
| 21–24 | C 大調卡農短編、前奏曲入門練習、愛麗絲片段、小音樂會 |

- 已檢視原有教程、5 組道場練習及 6 首預設曲目；調整不合理指法、移位提示及誇大的曲目名稱。較大跳進用「放開再整手移位」，不要求小手硬撐；原擴指操改為五指移位操。
- 指法是**建議**，並非唯一標準。小星星、愛麗絲等入門短編可停頓換手位，不代表原曲演奏指法；家長／老師需按手形確認，手腕放鬆，不舒服就停止。
- 程式只評**單音音高**，不驗證實際指法、節拍準確度或按鍵時值；兩手接力不是同時彈和弦。節奏模式只提供提示，不再把音高命中當作 PERFECT／GOOD 節拍評分。
- 過關需自己彈齊全部音，音高準確率至少 80%；示範、自動伴奏及未完成練習不會解鎖。練熟單手後，用「自己彈全部音」重新闖關。切換手別、速度或移調會重新開始；移調後原指法可能不適用。
- 舊關卡 ID 保留，已解鎖進度、星星、XP 及紀錄會遷移；未修改的舊預設曲目升級，真正改過的自訂曲目保留。資料仍只存在原瀏覽器，清除網站資料會刪除進度。

## Auto 收音

1. 開啟收音設定，預設使用「Auto 自動（建議）」。先保持安靜約 1–2 秒，等候「可以彈琴」再彈單音；校準期間不計音。
2. Auto 量度背景音，有限度調整門檻和增益顯示，避免持續音符被當作背景。遇到太吵、無有效訊號或未完成校準，停止彈奏／說話並按「重新校準」。
3. 仍可切換手動模式，自行調整收音加強與濾雜音；本次頁面內切回手動會保留手動設定。重新開 Mic、切換輸入裝置或回到頁面可能需要再次校準。
4. iPad 咪孔位置因型號而異，避免保護套遮住咪孔，嘗試調整朝向及與琴的距離。爆音要移遠，不是再加強增益。

收音分析留在本機，不上傳錄音。Auto **不是人聲分離或消噪保證**，也不能令遠處微弱訊號恢復品質。示範／節拍器播放時暫停收音判定，避免聲音回授被計分。Mic 跟彈前請停止示範及節拍器，並關閉合成琴聲／自動伴奏，減少揚聲器聲音被咪拾取。真實 iPad、琴聲和房間環境仍需實機試用驗證。

## 本地五線譜辨識

1. 在自訂歌曲加入琴譜圖片，可按次序加入多頁。
2. 按「本地五線譜辨識（免上傳）」。此按鈕只在瀏覽器分析圖片，不呼叫 AI 或上傳圖片；AI 按鈕是另一條雲端流程。
3. 用頁面選單檢查原圖上的藍色譜線、綠色音符及簡譜標籤，再手動校對、儲存。

新版按五線譜相對位置、符頭及符桿辨識，不再把圖片平均切成 16 格；不會在失敗時填入虛構旋律。逐頁、逐行保留音符次序，使用原圖分析（最長邊最多 1800px）。任何一頁沒有可辨識音符，或找到超出播放音域的音符，都會保留原有簡譜而不作部分匯入。

### 支援範圍及限制

- 適合清晰、正面、水平、完整的印刷**單聲部 C 大調高音譜表**；本地讀音搜尋範圍約 A3–G5。不是通用光學樂譜辨識器。
- 可產生四分、二分、全音符及基本八分音符初稿；`-` 表示 2 拍，`--` 表示 4 拍，`/2` 表示半拍。
- 手動簡譜／鍵盤播放支援 C3–G5，包括高音 `4'`、`#4'`、`5'`。
- **休止符、附點、調號、臨時升降記號、連音、反覆記號、低音譜號及和弦／多聲部未處理。** 休止時間不會保留，節奏並非完整還原。同一橫向位置只取一個音。
- 不會自動校正傾斜、透視、陰影或模糊。識別結果是待校對初稿，不是正確率保證；有綠圈也可能讀錯。

## 測試

使用 Node.js 18 或以上，無需安裝套件：

```powershell
node --test
```

測試涵蓋 24 關順序、指法資料、簡譜時值 round-trip、舊進度／曲目遷移、過關限制、示範與延遲回呼、玩家切換及速度／移調重置；亦涵蓋 Auto 收音控制器、手動切換、校準、噪音／爆音及音訊生命週期。琴譜測試包含合成譜線／音符、不同解析度、淡色符桿、基本時值、空白輸入、越界音、簡譜解析及多頁 UI 流程。整合測試使用 DOM／Canvas／音訊／網絡 mock，並檢查內嵌 JavaScript 語法；不等同真實瀏覽器視覺或 iPad 收音測試。

提供的 768×1085 灰階範例另有本機回歸測試：6 行譜表、76 個音符及次序摘要。圖片和完整抄譜不存入 repository。若本機持有該圖解碼後的 RGBA 原始位元組，可設定 `LOCAL_SHEET_SAMPLE_RGBA` 指向該檔，再執行以上命令；未設定時只跳過此範例測試。
