# starkeys

瀏覽器鋼琴練習工具。開啟 [index.html](index.html) 使用；部署時請一併保留 [local-sheet-recognition.js](local-sheet-recognition.js)、[piano-curriculum.js](piano-curriculum.js) 及 [microphone-auto.js](microphone-auto.js)。收音需要瀏覽器授權及 HTTPS（本機開發可用 localhost）。

## 24 關兒童教程

面向 5–8 歲初學者，每次約 5–10 分鐘；未熟可以重玩或用 0.6x 慢練。

| 關卡 | 重點 |
| --- | --- |
| 1–4 | 中央 C、右手五指、小羊、跳音程 |
| 5–8 | 左手三音及低音、長短拍、鈴兒響叮噹 |
| 9–12 | 歡樂頌、G 手位、小星星移位、左右手接力 |
| 13–16 | 右手穿指及 C 音階、左手跨指及音階 |
| 17–20 | 成對半拍、小蜜蜂接力、黑鍵、簡化小步舞曲 |
| 21–24 | C 大調卡農短編、前奏曲入門練習、愛麗絲片段、小音樂會 |

- 已檢視原有教程、5 組道場練習及預設曲目；簡譜庫現有 20 首常見、傳統或古典旋律（多為入門主題短編），有歌詞的旋律附 inline 歌詞，器樂曲不加歌詞；調整不合理指法、移位提示及誇大的曲目名稱。較大跳進用「放開再整手移位」，不要求小手硬撐；原擴指操改為五指移位操。
- 指法是**建議**，並非唯一標準。小星星、愛麗絲等入門短編可停頓換手位，不代表原曲演奏指法；家長／老師需按手形確認，手腕放鬆，不舒服就停止。
- 程式只評**單音音高**，不驗證實際指法、節拍準確度或按鍵時值；兩手接力不是同時彈和弦。節奏模式只提供提示，不再把音高命中當作 PERFECT／GOOD 節拍評分。手動簡譜可用 `0`、`0-`、`0--`、`0/2` 表示休止 1、2、4、半拍（`L0` 可指定左手譜表）；休止時示範不發聲，練習自動等待且不評音高。可在音符後加歌詞，如 `R1:1(小) R2:2(綿) R3-:3(羊)`，歌詞顯示於譜表音名下方；同一個字跨音符時，未完的音節用 `-` 標記，例如 `R5.:1(Hap-) R5.:1(py)`。
- 過關需自己彈齊全部音，音高準確率至少 80%；示範、自動伴奏及未完成練習不會解鎖。練熟單手後，用「自己彈全部音」重新闖關。切換手別、速度或移調會重新開始；移調後原指法可能不適用。
- 舊關卡 ID 保留，已解鎖進度、星星、XP 及紀錄會遷移；未修改的舊預設曲目升級，真正改過的自訂曲目保留。簡譜庫按 ✏️ 選曲後可按「刪除此曲」，確認後從此瀏覽器刪除（包括預設曲目），如正彈奏該曲會返回第一關。資料仍只存在原瀏覽器，清除網站資料會刪除進度。

## 練習畫面與譜表大小

- 頂部可直接開啟關卡、簡譜庫及和弦／音階；「練習設定」放模式、手別、速度、拍子、循環及收音設定。開／停 Mic、光亮／深色主題及全螢幕放右上角；示範及「重置」放譜表上方。點擊設定選單外或按 Escape 可收起選單。
- 「示範」「重置」「主題」「全螢幕」使用低飽和藍灰半透明底、清晰描邊及微光，突出點擊範圍而不搶譜表焦點；支援明暗主題、滑鼠懸停、按下及鍵盤焦點，點擊範圍至少 44×44px，減少動態效果設定下不縮放。
- 琴鍵上方「延音」及「撳鍵發聲」改為顯示開／關的 Toggle Pill；整個圓角按鈕都可點擊，觸控高度至少 44px。
- 大譜表在譜區高度足夠時垂直置中。譜區「譜表大小」可由 **100% 放大至 200%**，每次 10%；音符、指法及音名一同放大，不推開下方琴鍵。超出高度只在譜區內上下捲動；音符橫向跟隨照常運作。
- 放大後會跟隨目前音符；亦可手動捲動查看其他位置，直到下一粒音、縮放或版面尺寸改變才重新跟隨。縮放比例在本次頁面內保留，重新載入回到 100%。
- 單手曲目會壓縮沒有音符的譜表，並降至 30% 不透明度；雙手曲目保留兩行。指法圓圈移到符桿及譜線上方，音名各自放在所屬譜表下方。
- 深色主題的小節線使用不透明淺灰色，方便辨認小節分界；光亮主題維持原有顏色。
- 光亮主題統一關卡、簡譜庫、玩家／成就、和弦／音階、收音及完成視窗的卡片、輸入欄、文字與波形配色；未解鎖項目用虛線區分，不再整張淡化。主題選擇會保留，亦控制原生表單及 Tailwind 深色樣式，不受系統深色偏好蓋過；黑白琴鍵、主要按鈕白字及視窗遮罩維持原樣。

## iPad／Safari 全螢幕

- iOS／iPadOS（包括 iPad 桌面 UA）使用 CSS 偽全螢幕，不呼叫原生 Fullscreen API，避免 WebKit 左上角關閉按鈕；再次按全螢幕可退出。其他平台保留原生全螢幕，不支援或被拒絕時才使用偽全螢幕。
- 沿用沉浸模式隱藏頂部統計列；內容保留四邊安全區，偽全螢幕高度跟隨可見視窗及旋轉。舊 Safari 有百分比高度後備，並攔截背景／捲動邊界拖動，保留譜表及視窗內捲動、滑桿和琴鍵觸控。
- 已包含 `apple-mobile-web-app-capable`、`apple-mobile-web-app-status-bar-style` 及 `viewport-fit=cover`。Safari 分頁的網址列由系統控制，偽全螢幕不能保證收窄或完全隱藏；需要無網址列體驗時，請在 Safari 分享選單「加入主畫面」後從圖示開啟。
- iPad Air 2／iPadOS 15.8.x 實機驗收：橫直向切換、進出偽全螢幕、網址列展開／收窄、200% 譜表及彈窗捲動邊界、多指彈琴，以及主畫面啟動後安全區均需檢查。桌面模擬測試不能替代實機驗證。

## Auto 收音

1. 開啟收音設定，預設使用「Auto 自動（建議）」。先保持安靜約 1–2 秒，等候「可以彈琴」再彈單音；校準期間不計音。
2. Auto 量度背景音，有限度調整門檻和增益顯示，避免持續音符被當作背景。遇到太吵、無有效訊號或未完成校準，停止彈奏／說話並按「重新校準」。
3. 仍可切換手動模式，自行調整收音加強與濾雜音；本次頁面內切回手動會保留手動設定。重新開 Mic、切換輸入裝置或回到頁面可能需要再次校準。
4. iPad 咪孔位置因型號而異，避免保護套遮住咪孔，嘗試調整朝向及與琴的距離。爆音要移遠，不是再加強增益。

收音分析留在本機，不上傳錄音。Auto **不是人聲分離或消噪保證**，也不能令遠處微弱訊號恢復品質。示範／節拍器播放時暫停收音判定，避免聲音回授被計分。Mic 跟彈前請停止示範及節拍器，並關閉合成琴聲／自動伴奏，減少揚聲器聲音被咪拾取。真實 iPad、琴聲和房間環境仍需實機試用驗證。

## 本地五線譜辨識

1. 在自訂歌曲加入琴譜圖片，可按次序加入多頁。
2. 按「本地五線譜辨識（免上傳）」。此按鈕只在瀏覽器分析圖片，不呼叫 AI 或上傳圖片；AI 按鈕是另一條雲端流程。
3. 用頁面選單檢查原圖上的藍色譜線、綠色音符及簡譜標籤，再手動校對、儲存。

新版按五線譜相對位置、符頭及符桿辨識，不再把圖片平均切成 16 格；不會在失敗時填入虛構旋律。逐頁、逐行保留音符次序，使用原圖分析（最長邊最多 1800px）。任何一頁沒有可辨識音符，或找到超出播放音域的音符，都會保留原有簡譜而不作部分匯入。

### 支援範圍及限制

- 適合清晰、正面、水平、完整的印刷**單聲部 C 大調高音譜表**；本地讀音搜尋範圍約 A3–G5。不是通用光學樂譜辨識器。
- 可產生四分、二分、全音符及基本八分音符初稿；`-` 表示 2 拍，`--` 表示 4 拍，`/2` 表示半拍。
- 手動簡譜／鍵盤播放支援 C3–G5，包括高音 `4'`、`#4'`、`5'`。
- **休止符、附點、調號、臨時升降記號、連音、反覆記號、低音譜號及和弦／多聲部未處理。** 休止時間不會保留，節奏並非完整還原。同一橫向位置只取一個音。
- 不會自動校正傾斜、透視、陰影或模糊。識別結果是待校對初稿，不是正確率保證；有綠圈也可能讀錯。

## 測試

使用 Node.js 18 或以上，無需安裝套件：

```powershell
node --test
```

全螢幕回歸測試可用 `node --test tests\fullscreen.test.js tests\practice-ui.test.js`，涵蓋 iOS／桌面 UA 分流、原生 API 成功／拒絕／舊式 void 回傳、退出狀態同步、可見視窗高度及觸控捲動邊界。

測試涵蓋 24 關順序、指法資料、簡譜時值 round-trip、舊進度／曲目遷移、過關限制、示範與延遲回呼、玩家切換及速度／移調重置；亦涵蓋 Auto 收音控制器、手動切換、校準、噪音／爆音及音訊生命週期。琴譜測試包含合成譜線／音符、不同解析度、淡色符桿、基本時值、空白輸入、越界音、簡譜解析及多頁 UI 流程。譜表測試涵蓋單／雙手佈局、指法間距、100–200% 縮放限制、DPR、跟隨／手動捲動及控制項語意。整合測試使用 DOM／Canvas／音訊／網絡 mock，並檢查內嵌 JavaScript 語法；不等同真實瀏覽器視覺或 iPad 收音測試。

另有選用的真實 Chromium／Edge 主題測試（Node.js 22+，無需安裝 npm 套件，須能連線載入 Tailwind CDN）：

```powershell
$env:THEME_TEST_BROWSER = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
node --test tests\theme-ui.test.js
```

此測試使用獨立臨時瀏覽器資料夾，檢查 1280px／390px 下的主畫面、視窗、動態卡片、圖片預覽、一般文字對比、原生表單及收音波形配色，並驗證琴鍵不變、深色還原及重新載入保留主題。配色檢查停用過場動畫，不代替 Safari／iPad 實機檢查；未設定 `THEME_TEST_BROWSER` 時會跳過瀏覽器部分。

提供的 768×1085 灰階範例另有本機回歸測試：6 行譜表、76 個音符及次序摘要。圖片和完整抄譜不存入 repository。若本機持有該圖解碼後的 RGBA 原始位元組，可設定 `LOCAL_SHEET_SAMPLE_RGBA` 指向該檔，再執行以上命令；未設定時只跳過此範例測試。
